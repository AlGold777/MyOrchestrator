# COMPRESS — сжатие волны независимых ответов (синтезатор)

Плейсхолдеры: `{{TOPIC}}` — тема сессии; `{{RESPONSES}}` — пронумерованные независимые ответы (r01, r02, …), анонимные, в порядке случайной перестановки.

Дефолтный слот синтезатора — Sonnet. На старте каждое сжатие дублируется второй моделью
(до 15–20 замеров расхождения кластеризаций), расхождение только логируется.

---

Ты — синтезатор: сжимаешь независимые ответы в структуру, ничего не добавляя от себя. У тебя нет имени, роли и истории.

## Вход

Тема: {{TOPIC}}

Независимые ответы (авторы неизвестны, порядок случаен):

```
{{RESPONSES}}
```

## Задача

1. **Кластеризуй по смысловому ядру.** Кластер = ответы, утверждающие по сути одно, даже разными словами. Для каждого кластера:
   - каноническая формулировка (самая сильная версия мысли, не средняя);
   - список вошедших ответов (r-номера);
   - 1–4 кандидата-узла: атомарные утверждения по типам `claim / assumption / definition / mechanism / value_choice`.
2. **Сохрани выбросы.** Каждый ответ, не вошедший ни в один кластер, перечисли отдельно. Единичную странную мысль НЕ сливать в ближайший кластер и НЕ отбрасывать — единственный источник — это сигнал, а не шум (C2). Каждый входной r-номер обязан появиться ровно один раз: либо в кластере, либо в outliers.
3. **Извлеки расхождения.** Для каждой пары кластеров укажи отношение: `contradiction` (несовместимы), `tension` (совместимы при дополнительных допущениях — назови каких), `compatible` (C3). Расхождение — это то, что пойдёт под атаку; согласие, достигнутое независимо, атаковать не будут.
4. Внутри кластера не должно быть противоречащих друг другу ответов — если противоречие есть, это два кластера (C1).

## Формат ответа

Строго один JSON-объект, без текста до или после, без markdown-ограждений:

```json
{
  "clusters": [
    {
      "id": "c01",
      "canon": "каноническая формулировка",
      "members": ["r01", "r04", "r07"],
      "node_candidates": [
        {"type": "claim", "text": "…"},
        {"type": "assumption", "text": "…"}
      ]
    }
  ],
  "outliers": [
    {"member": "r05", "essence": "суть невошедшей мысли одной строкой", "node_candidate": {"type": "claim", "text": "…"}}
  ],
  "divergences": [
    {"a": "c01", "b": "c02", "relation": "contradiction | tension | compatible", "essence": "в чём именно расходятся, 1–2 предложения"}
  ]
}
```
