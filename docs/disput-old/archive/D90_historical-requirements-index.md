# D90. Архив исходных требований Disput

Документы D91–D97 — исходные задания, на основании которых развивалась система. Они сохранены для provenance, но не являются текущими спецификациями. Актуальные контракты находятся в D1–D11 и D21; планы и отчёты — в `reports/`, история изменений — в `CHANGELOG.md`.

- D91 — исходный prompt audit;
- D92 — Must Have, раздел I;
- D93 — необходимая вторая очередь, раздел II;
- D94 — качественные улучшения, раздел III;
- D95 — малые улучшения, раздел IV;
- D96 — экспериментальные идеи, раздел V;
- D97 — охранные правила против избыточной формализации, раздел VI.

Дубли этих семи файлов удалены из двух прежних каталогов; сохранена одна нумерованная копия каждого документа.

D98 и D99 — исходные HTML-прототипы карты; они также не являются production UI.
