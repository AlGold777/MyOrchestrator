# D13. FreeTalk experiments log

В этот append-only журнал заносятся только реально выполненные сравнительные и
живые прогоны. Fixture/unit/browser проверки не выдаются за качество ответов LLM.

Для каждой записи обязательны: дата, версия расширения, задача, модели,
одинаковый ресурсный бюджет, сравниваемые режимы, terminal outcome, стоимость,
время, число принятых/отклонённых изменений, extraction rate, human actions и
ссылка на локальный обезличенный отчёт. Prompt и ответы сюда не копируются.
