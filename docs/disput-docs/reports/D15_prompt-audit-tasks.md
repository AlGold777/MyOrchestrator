# D15. Prompt audit: fixed tasks

Дата фиксации: 2026-07-16. Эти задачи являются baseline для Z3 и будущего T12.

## З-1 — аналитическая

Сравни два подхода к архитектурному решению: сначала benchmark на реальных сценариях или сначала строгая схема артефактов и аудитов. Оцени качество, стоимость, обратимость и риск ложной уверенности. Отвечай по-русски.

## З-2 — фактологическая

Объясни, какие ограничения MV3 и чужих веб-интерфейсов мешают обещать exactly-once доставку ответа. Отдели гарантии расширения от свойств вкладки и провайдера. Укажи нужные диагностические события. Отвечай по-русски.

## З-3 — red-team предложение

Предложи небольшую архитектуру восстановления участника Debate после dropout: передай заменяющей модели только тему, роль, последнюю волну и filtered state. Найди слабые места и критерии отклонения идеи. Отвечай по-русски.
