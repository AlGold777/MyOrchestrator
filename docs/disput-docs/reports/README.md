# Отчёты и планы Disput

Эта папка не является нормативной документацией. Здесь хранятся планы
внедрения, результаты аудитов, экспериментальные записи и незавершённые задачи.

- D12 — план внедрения FreeTalk MVP;
- D13 — журнал реальных экспериментов FreeTalk;
- D14–D15 — prompt-аудит и фиксированные задачи для него;
- D16–D18 — исполнительские отчёты по этапам работ;
- D19 — текущие открытые задачи;
- D20 — концепция и план универсального движка «Обсуждение темы».

Все фактические изменения проекта фиксируются только в
[`../../CHANGELOG.md`](../../CHANGELOG.md). Отчёт может содержать контекст или
результат проверки, но не заменяет запись в changelog и не является источником
текущего архитектурного контракта.
