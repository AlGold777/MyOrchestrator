# Полевая проверка телеметрии — 2026-08-02

## Итог

Проверены все восемь JSON-выгрузок, доступных в `Downloads`: версии расширения
2.81.220, 2.81.221 и 2.81.227, от 267 до 563 событий и от 9 до 21 инцидента.
Полевой ворот пройден:

- во всех восьми случаях исходный ledger перенесён без изменения хеша;
- из каждого ledger построены валидные текущие `canonical-evidence` и
  `full-forensic`;
- выполнено 826 сравнений embedded/standalone/core по всем семи задачам и всем
  инцидентам; различий — 0;
- необъяснённых ошибок исходных файлов — 0;
- исходные файлы не изменялись и не копировались в репозиторий.

Проверка воспроизводится командой:

```bash
npm run validate:telemetry-field -- /path/to/telemetry-1.json /path/to/telemetry-2.json
```

Она выводит только метаданные контейнера, размеры, хеш файла, коды проверок и
агрегированные результаты. Prompt, ответ и содержимое событий в вывод не
попадают.

## Роль выжимки

Выжимка полезна для быстрого первичного разбора: она содержит версию, run scope,
количество событий, краткие состояния моделей и предупреждает, что отсутствие
сигнала нельзя считать отрицательным результатом. Но она намеренно не содержит
полный ledger, registry, hashes и все типы событий, поэтому не поддерживает
проверку целостности, offline replay и доказательство диагноза.

Выжимка и ближайший JSON являются последовательными snapshot, а не двумя
представлениями одного неизменного boundary. Например, указанная пара содержит
424 и 426 событий, а последняя доступная пара — 558 и 563. Поэтому для первичной
оценки достаточно выжимки; для воспроизводимой диагностики и полевого ворота
нужен JSON или canonical evidence.

## Критерий ворот

Проверка завершается ошибкой, если хотя бы один исходный код не объяснён
версией, ledger hash изменился, новый canonical/full невалиден или хотя бы одно
семантическое сравнение расходится. В этом прогоне все условия выполнены.

С v2.81.239 «объяснён версией» означает точное совпадение кода, полного текста,
структурного отсутствия мигрированного поля и ожидаемого количества повторений.
Совпадения только по `S22` либо номеру старой версии недостаточно.
